## Context

Observed 2026-10-15 (PR #1632, branch `ai-sdlc/decisions-sync`, head edcc1ac1): the reconciler classifies the PR as `docs` (`reconcile.ts` `PrKind = 'task' | 'docs' | 'release'`, line 64), lands it through `cli-merge-if-eligible` with the task/docs source kind, and the gate refuses: "no backlog task id could be derived from head branch ai-sdlc/decisions-sync or the PR title". The reconciler then routes the PR to the planner on every tick (route-to-planner, no-match). `cli-merge-if-eligible` already accepts `--source-kind decisions-sync` (`merge-if-eligible.ts:126`) and arms the PR when invoked by hand with it. The sync PR is regenerated by every decision write (`persistDecisionLog`, `remote-persist.ts`), so the misclassification recurs for the life of the hierarchy, each time costing a planner route and a manual arm.

**Five-step review (requirements first).** Requirement questioned: "the reconciler lands only task and docs PRs". The sync PR is machine-generated, docs-only and trusted, and already has a sanctioned landing kind; nothing justifies excluding it. Delete: the planner route for this PR. Simplify: one more `PrKind` with a fixed branch match (`DECISIONS_SYNC_BRANCH`), landed with its own source kind. Accelerate: nothing. Automate: the landing is already deterministic (automation ladder rung 1).

## Fix

1. `reconcile.ts`: add `'decisions-sync'` to `PrKind`; `classifyKind` returns it when `headBranch === DECISIONS_SYNC_BRANCH` (import the constant from `remote-persist.ts`; test the branch before the docs/task heuristics). The landing action for that kind is the same arm/merge step as `docs`, invoked with `--source-kind decisions-sync`. No task id lookup, no DoR, no attestation (docs-only).
2. A `decisions-sync` PR whose head changed since the last landing record (the branch is lease-pushed on every decision write) is re-armed, never routed to the planner; keep `report-only` for a red one, with the rate-limit rule of AISDLC-926.
3. `docs/operations/cli-hierarchy.md`: list the fourth kind and its source kind.
4. Tests (`reconcile.test.ts`): branch `ai-sdlc/decisions-sync` → kind `decisions-sync`, landing args contain `--source-kind decisions-sync`; a title-only match does not classify (branch is the key); existing task/docs/release cases unchanged.
