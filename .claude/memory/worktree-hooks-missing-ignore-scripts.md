core.hooksPath is `.husky/_` (gitignored, generated by husky's `prepare`). A worktree installed with `pnpm install --ignore-scripts` lacks it, so git silently runs NO pre-commit/commit-msg/pre-push hooks. On 2026-10-03 this let 682 and 686 merge without the local gate chain. Executors reached for --ignore-scripts because a plain install fails on the default Node 22.19.0 (lint-staged needs >=22.22.1).

**Why:** silent gate bypass, not an error.
**How to apply:** put `$HOME/.nvm/versions/node/v22.23.2/bin` first on PATH in the same Bash call, run plain `pnpm install --frozen-lockfile`, and confirm `<worktree>/.husky/_` exists before any commit. AISDLC-693 makes setup fail closed on this.
